## Pension amounts — order of 28 February 2019.

Order No. F 9(05)(12-II) पेंशन/सा.न्या.अ.वि./2014-15/15172, Jaipur, 28.02.2019, Principal Secretary Akhil Arora; **effective 01.03.2019**. Amends rule 2(iv) of the Rajasthan Social Security Old Age, Widow, Destitute and Divorcee Pension Rules, 2013. [PDF](https://sje.rajasthan.gov.in/increase%20order%20for%20widow%20pension.pdf)

| # | Scheme | Age | ₹ a month |
|---|---|---|---|
| 1 | Old age (Mukhyamantri Vriddhjan Samman Pension) | under 75 | **750** |
|   |  | 75+ | **1,000** |
| 2 | Widow, destitute (parityakta) and divorcee (Mukhyamantri Ekal Nari Samman Pension) | 18–54 | **500** |
|   |  | 55–59 | **750** |
|   |  | 60–74 | **1,000** |
|   |  | 75+ | **1,500** |

> "1. 75 वर्ष से कम आयु के पेंशनर को रू. 750/- प्रति माह 2. 75 वर्ष व अधिक आयु के पेंशनर को रू. 1000/- प्रति माह"
>
> "1. 18 वर्ष व अधिक किन्तु 55 वर्ष से कम आयु की विधवा, परित्यकता एवं तलाकशुदा पेंशनर को रू. 500/- प्रति माह … 4. 75 वर्ष व अधिक आयु की विधवा, परित्यकता एवं तलाकशुदा पेंशनर को रू. 1500/- प्रति माह"

- **Other pension:** "यदि प्रार्थी … किसी … अन्य स्त्रोत से पेंशन, निर्वाह भत्ता या अन्य कोई लाभ प्राप्त कर रहा हो तो वह उक्त वर्णित पेंशन या पूर्व में प्राप्त लाभ में से जो भी लाभदायक हो, पाने का अधिकारी होगा।" — the more beneficial one, not both.

! **Probably superseded.** Non-official sources report a flat minimum of ₹1,000–₹1,150 (and ₹1,450 in some) since 2022–2025. The page title says "increase", but its embedded file is this 2019 order. Find the latest order before drafting.

? **Eligibility** (non-official, to confirm on an official page): old age — women 55+, men 58+; Ekal Nari — widow, divorced, destitute or abandoned woman 18+, no regular income or annual income from all sources under ₹48,000. The ages here are unusual (55 / 58, not 60) — confirm.
