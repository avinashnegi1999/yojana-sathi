## What the project is

**Yojana Sathi** (repo: `E:\project Scheme Sathi`, GitHub: `avinashnegi1999/yojana-sathi`, branch `main`) is a Telegram bot that screens India's unorganised-sector workers against government welfare schemes in Hindi or English, and ends with a filled application sheet and an address to walk to. Live bot: @YojanaSathiBot. Site: https://avinashnegi.com/yojana-sathi/. Hackathon entry for Code for India's "Code for a Billion 2026" (deploy gate 11 Oct 2026, submissions close 15 Nov 2026), and a portfolio piece.

**The design premise:** the expensive failure is a confident wrong answer. A wrong "yes" sends a worker on a day-long trip to a service centre that costs a day's wage. So:

- Eligibility is decided by a **deterministic rule engine** (`sathi/rules/`) over TOML scheme files in `data/schemes/`. A language model is **structurally barred** from that package — a test fails if it imports one.
- Verdicts are three-valued: `ELIGIBLE | INELIGIBLE | UNKNOWN`. UNKNOWN whenever an answer is missing or a rule is unverified. Never fill a gap with a default.
- Every scheme value carries a `source_url` to an official page. **Never invent a scheme rule** — not a threshold, an age, an amount, or an exclusion. An unresearched value is the literal string `"TODO"`, never `0`.
- A scheme returns real verdicts only when a named human has signed it: `verified_by = "Avinash Negi, checked <date>"`. Only Avinash can sign, via `python3 -m sathi.review` (refuses non-TTY). Unsigned files return UNKNOWN to everyone.
- Zero third-party dependencies. Python 3.11+ stdlib only. `python3 check.py` runs everything and must pass before anything is called done.
- No PII anywhere: no name, phone or Aadhaar field exists. Event log holds coarse bands under a random per-session id.
